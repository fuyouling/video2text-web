# 02 · 产品定位与卖点

> 模块定位：界定官网"对谁说、说什么、差异在哪"，作为所有页面文案与结构的依据。
> 上级索引：[00-overview.md](./00-overview.md)

## 2.1 一句话定位（Value Proposition）

> **Local, private audio & video transcription and summarization.**
> 100% 本地离线运行的音视频转写与智能总结工具，隐私不出本机。

核心心智：**隐私安全 + 本地性能 + 零门槛**。

## 2.2 目标用户

| 用户群 | 典型场景 | 关注点 |
| --- | --- | --- |
| 内容创作者 / 博主 | 视频字幕、脚本整理 | 离线隐私、字幕导出、多语言 |
| 研究者 / 学生 | 讲座、访谈、会议录音转写 | 准确率、长音频、增量处理 |
| 开发者 / 技术用户 | CLI 批处理、API Key 接入在线模型 | 灵活性、可脚本化 |
| 企业 / 团队（潜在） | 内部会议记录 | 数据不出本机、合规 |

## 2.3 核心卖点（官网内容依据）

基于 `video2text` 现有能力，官网应突出以下卖点（对应首页 6 张特性卡片）：

1. **100% 本地离线（Local & Private）**
   - 音视频不上云，数据不出本机，隐私安全（核心差异化）。
   - 文案重点：对比"云端转写会读取你的文件"，强调"本地处理、零上传"。
2. **GPU 加速转写（GPU Accelerated）**
   - 基于 faster-whisper + CUDA 12 / cuDNN 9，large-v3-turbo 模型。
   - 文案重点：性能数据、比 CPU 快 N 倍、显存占用可控。
3. **多语言与自动检测（Multi-language）**
   - 支持多语言转写与总结，语言自动检测。
   - 文案重点：支持语言列表、自动检测省心。
4. **智能总结（AI Summary）**
   - 本地 Ollama 大模型生成摘要；同时支持在线模型。
   - 文案重点："转写 + 总结"一步到位，可导出结构化结果。
5. **灵活的模型策略（Flexible Models）**
   - 内置离线模型 + 可接入在线转写 API。
   - 文案重点：既有免费离线，也能接 NVIDIA 等在线端点，按需选择。
6. **桌面 + CLI 双模式（Desktop & CLI）**
   - Windows 桌面端，提供 GUI 与 CLI 两种使用方式。
   - 文案重点：图形界面开箱即用，CLI 可脚本化/批处理；一次购买（Pro）多机可用。

> **Pro 权益设计约束（重要）**：卖点中"在线模型额度/高级模型额度"若指"由开发者代付的云端额度"，则与 **$9.9 一次性买断** 的商业模式冲突（单次付款承担无限额的持续云成本，不可持续）。Pro 权益应限定为**本地可验证、无持续云成本**的能力，在线模型继续采用 **BYOK（用户自带 API Key）** 模式（用户用自己的 NVIDIA / OpenAI 等密钥，由桌面端本地管理与存储，与官网 Pro 无关）。建议 Pro 权益聚焦：批量与增量处理增强、优先支持、多设备 License、高级本地导出/格式、早期功能体验等。
>
> 若桌面端为开源软件，需在 [08 §8.7](./08-license-design.md) 处理"开源下客户端授权可被绕过"的风险，避免在文案中承诺无法强制兑现的 Pro 功能。

## 2.4 差异化对比（信任背书区块素材）

建议首页"对比/信任背书"区块用简洁对照表，突出：

| 维度 | video2text（本地） | 云端转写 SaaS |
| --- | --- | --- |
| 数据隐私 | 不出本机 | 上传到服务器 |
| 网络依赖 | 离线可用（在线模型可选） | 需联网 |
| 成本 | 桌面免费 + Pro 买断 $9.9 | 订阅制月费 |
| 性能 | 支持本地 GPU 加速（有独显时） | 受服务端队列影响 |
| 模型选择 | 离线内置 + 在线可接（BYOK） | 平台固定 |

> 注意：对比仅陈述事实，不贬低竞品；强调"适合注重隐私与一次性付费的用户"。GPU 加速需用户具备受支持的独立显卡，无 GPU 时回退 CPU，文案不得暗示所有机器都能获得同等性能。

## 2.5 内容语气与品牌调性

- **专业但平易**：技术准确，避免生僻术语堆砌；面向非技术用户也能看懂。
- **隐私优先**：在所有关键页面反复强化"Local & Private"。
- **买断友好**：Pro 强调"one-time $9.9，永久可用"，与订阅制形成对比。
- **英语优先**：首页/默认文案为英文；中文为同等重要地位的第二语言。
