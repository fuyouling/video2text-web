もし video2text が役に立ったなら——講義や会議、お気に入りの動画の文字起こしに使っているなら——ぜひ応援してください。

一番簡単な応援方法は、**GitHub でプロジェクトにスターをつけること**です：

[⭐ GitHub で video2text にスターをつける](https://github.com/fuyouling/video2text)

スターは多くの人にこのツールを知ってもらう助けになり、私たちが改善を続ける励みになります。フィードバックや不具合がありましたら、リポジトリで Issue を開いてください。コミュニティの一員になっていただき、ありがとうございます！
