Wenn dir video2text geholfen hat — egal ob zum Transkribieren von Vorlesungen,
Meetings oder deinen Lieblingsvideos — freuen wir uns über deine Unterstützung.

Am einfachsten unterstützt du uns, indem du dem Projekt **einen Stern auf GitHub
gibst**:

[⭐ video2text auf GitHub ster­nen](https://github.com/fuyouling/video2text)

Sterne helfen mehr Menschen, das Tool zu entdecken, und motivieren uns, es
weiterzuentwickeln. Wenn du Feedback hast oder auf Probleme stößt, erstelle
gerne ein Issue im Repository. Danke, dass du Teil der Community bist!
