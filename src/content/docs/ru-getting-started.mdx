Это руководство проведёт вас по этапам: загрузка зависимостей, выбор входных и выходных данных, выбор моделей транскрипции и резюмирования, а также просмотр результатов.

> Применимо к настольному приложению video2text **v2.6.3**.

## 1. Загрузка зависимостей

При первом запуске video2text необходимо получить локальные зависимости времени выполнения (движок транскрипции и модели). Это происходит один раз.

**Подтвердите загрузку**

Когда появится запрос, подтвердите, что хотите загрузить необходимые зависимости.

<Image src={s1} alt="Подтвердите загрузку зависимостей" width={1280} />

**Идёт загрузка**

Дождитесь завершения загрузки зависимостей. Ход выполнения отображается в интерфейсе.

<Image src={s2} alt="Загрузка зависимостей" width={1280} />

**Загрузка завершена**

Как только загрузка успешно завершится, можно приступать к транскрипции.

<Image src={s3} alt="Зависимости успешно загружены" width={1280} />

## 2. Выберите входной файл и выходную папку

Выберите медиафайл для обработки и место сохранения результатов.

<Image src={s4} alt="Выберите входной файл и выходную папку" width={1280} />

## 3. Выберите модели транскрипции и резюмирования

Далее выберите модели для транскрипции и резюмирования.

Модель транскрипции по умолчанию — `faster-whisper-large-v3-turbo-ct2`. Если вы хотите переключиться на другую модель, см. остальные статьи документации.

В этом руководстве для демонстрации используется **онлайн-модель**. Если вы предпочитаете запускать локальную модель через Ollama, обратитесь к другим статьям или к [документации Ollama](https://ollama.com) за инструкциями по настройке.

**Проверьте доступные модели NVIDIA API**

Если вы используете онлайн-провайдера, перед запуском можно проверить, какие модели NVIDIA API доступны.

<Image src={s5} alt="Проверьте доступные модели NVIDIA API" width={1280} />

**Переключение провайдера модели**

Переключитесь на провайдера модели (например, между локальным и онлайн-API), который хотите использовать для транскрипции.

<Image src={s6} alt="Переключение провайдера модели" width={1280} />

> Модель резюмирования использует разумное значение по умолчанию, поэтому отдельного снимка экрана для неё нет. При необходимости её можно изменить в тех же настройках модели.

## 4. Просмотр результатов

После обработки просмотрите как транскрипцию, так и сгенерированное резюме.

**Результат транскрипции**

Транскрипция завершена, результат отображается в интерфейсе.

<Image src={s7} alt="Экран результата транскрипции" width={1280} />

**Результат резюме**

Резюме успешно сформировано и показывается вместе с транскрипцией.

<Image src={s8} alt="Экран результата резюме" width={1280} />

**Просмотр резюме в формате Markdown**

Переключитесь в режим Markdown, чтобы скопировать или экспортировать резюме в чистом формате Markdown.

<Image src={s9} alt="Просмотр резюме в формате Markdown" width={1280} />

## Следующие шаги

- Включите ускорение GPU для более быстрой транскрипции.
- Подключите локальную модель для резюме или используйте собственный ключ онлайн-модели.
