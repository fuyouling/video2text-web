> 데스크톱 앱 video2text **v2.6.3**에 적용됩니다.

이 가이드는 두 단계로 다른 전사 모델로 전환하는 방법을 설명합니다.

## 1. 모델 파일을 models 디렉터리에 복사하기

모델 파일을 앱의 `models` 디렉터리에 넣습니다. 각 모델은 자체 하위 폴더에 있어야 합니다.

<Image src={s1} alt="모델 파일을 models 디렉터리에 복사" width={1280} />

## 2. 설정을 편집하고 모델 경로 지정하기

설정을 열고 모델 폴더 이름을 **model path(모델 경로)** 필드에 입력하면 video2text가 해당 모델을 불러옵니다.

<Image src={s2} alt="모델 경로에 모델 폴더 이름 입력" width={1280} />

저장 후 변경 사항을 적용하려면 video2text를 다시 시작(또는 모델을 다시 불러오기)하세요.
