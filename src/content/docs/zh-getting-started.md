## 安装

从 [GitHub Releases](https://github.com/fuyouling/video2text/releases) 获取 Windows 安装版并运行，无需注册账号。

## 转写文件

1. 打开 video2text，选择本地的音视频文件。
2. 选择语言（或保持自动检测）。
3. 开始转写，全程在本地完成。

## 下一步

- 开启 GPU 加速以加快转写。
- 接入本地模型生成总结，或自带在线模型 Key。
